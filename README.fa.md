# CineScope — راهنمای فارسی

بات تلگرام دکمه‌محور برای جست‌وجوی فیلم و سریال، نمایش اطلاعات، فصل و قسمت، اخبار، فهرست تماشا و پیشنهاد آثار مشابه. اجرا روی Cloudflare Workers است و به VPS نیاز ندارد.

## امکانات

- جست‌وجوی فیلم و سریال با OMDb
- نمایش عنوان، سال، خلاصه داستان، ژانر، مدت، بازیگران، کارگردان/نویسنده، زبان، کشور، جوایز و امتیاز IMDb در صورت موجود بودن
- نمایش فصل‌ها و قسمت‌های سریال در حد داده‌هایی که OMDb ارائه می‌کند
- اخبار سینمایی از Google News RSS
- پیشنهاد آثار مشابه با AI و تأیید وجود هر عنوان در OMDb
- Watchlist شخصی هر کاربر
- مدیریت حداکثر پنج کلید AI برای هر کاربر
- رمزنگاری اطلاعات کاربران با AES-256-GCM پیش از ذخیره در Cloudflare KV
- خواندن متادیتای عمومی صفحه از URLهایی که کاربر از `dornatv.com`، `movieplus.top` یا `animex.pro` می‌فرستد

## منبع اصلی اطلاعات: OMDb

OMDb منبع اصلی کاتالوگ است. بات از جست‌وجوی `s=`، جزئیات عنوان با `i=` و اطلاعات فصل سریال با `i=` به‌همراه `Season=` استفاده می‌کند. شناسه‌ها از نوع IMDb مانند `tt3896198` هستند؛ نه شناسه عددی TMDb.

کلید OMDb باید به‌صورت Secret در Cloudflare تنظیم شود و نباید داخل کد یا ریپو نوشته شود:

```bash
npx wrangler secret put OMDB_API_KEY
```

وقتی Wrangler درخواست کرد، کلید حساب OMDb را وارد کن. کلیدی که داخل پیام چت فرستادی عمداً در فایل‌های پروژه قرار داده نشده است. اگر آن کلید واقعی و حساس است و نمی‌خواهی در تاریخچه چت باقی بماند، آن را تعویض کن و مقدار جدید را فقط به‌عنوان Worker Secret ثبت کن.

OMDb سرویس ترند، پیشنهاد آثار مشابه یا موجود بودن فیلم در سرویس‌های پخش را ارائه نمی‌کند. بنابراین:
- دکمه ترند، تیترهای خبری سرگرمی را نمایش می‌دهد، نه رتبه‌بندی جعلی فیلم‌ها.
- آثار مشابه را AI پیشنهاد می‌دهد و بات قبل از نمایش، وجود آن‌ها را در OMDb بررسی می‌کند.
- بات ادعای موجود بودن فیلم در پلتفرم‌های پخش را نمی‌کند.

## استفاده از سایت‌های معرفی‌شده

دکمه **Site metadata** یک URL صفحه جزئیات از این دامنه‌ها می‌گیرد:

- `dornatv.com`
- `movieplus.top`
- `animex.pro`

بات فقط متادیتای عمومی قابل‌مشاهده مانند عنوان، خلاصه، تاریخ/سال، ژانر، بازیگران، کارگردان و امتیاز را از JSON-LD یا OpenGraph می‌خواند. لینک پلیر، ویدئو یا دانلود استخراج، بازپخش یا نمایش داده نمی‌شود. این قابلیت به وجود متادیتای ساختاریافته در صفحه بستگی دارد و ممکن است برخی سایت‌ها درخواست خودکار را مسدود کنند.

## تنظیم AI / Hydrogen

مدل AI از تنظیمات Worker انتخاب می‌شود:

- `AI_API_MODE = "google"` برای API مستقیم Google Gemini
- `AI_API_MODE = "responses"` برای درگاه سازگار با OpenAI Responses API

در حالت درگاه، `AI_API_BASE_URL` باید آدرس مستندشده همان سرویس با پایان `/v1` باشد و `GEMINI_MODEL` باید شناسه دقیق برگشتی از فهرست مدل‌های همان حساب باشد. اسم نمایشی Hydrogen 4 به‌تنهایی شناسه API را مشخص نمی‌کند. کاربر نیز باید کلید همان ارائه‌دهنده را وارد کند.

در خطای 429، بات محدودیت را اعلام می‌کند و کلید را Rate Limited می‌کند؛ کلیدها برای دور زدن سهمیه به‌صورت خودکار چرخانده نمی‌شوند.

## پیش‌نیازها

- توکن بات تلگرام از BotFather
- حساب Cloudflare با Workers و KV
- کلید OMDb
- کلید AI هر کاربری که قابلیت AI می‌خواهد

## نصب و استقرار

۱. نصب وابستگی‌ها:

```bash
npm install
```

۲. ساخت KV:

```bash
npx wrangler kv namespace create CINE_KV
```

شناسه خروجی را در `wrangler.toml` جایگزین `REPLACE_WITH_YOUR_KV_NAMESPACE_ID` کن.

۳. ساخت کلید رمزنگاری ۳۲ بایتی:

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
```

این مقدار را امن نگه دار. تغییر یا گم‌شدن آن، اطلاعات قبلاً رمزنگاری‌شده را غیرقابل‌خواندن می‌کند.

۴. تنظیم Secretها:

```bash
npx wrangler secret put BOT_TOKEN
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET
npx wrangler secret put ENCRYPTION_KEY
npx wrangler secret put OMDB_API_KEY
```

۵. Deploy:

```bash
npm run deploy
```

۶. ثبت Webhook در PowerShell:

```powershell
$env:BOT_TOKEN = "توکن_بات"
$env:WORKER_URL = "https://آدرس-ورکر"
$env:TELEGRAM_WEBHOOK_SECRET = "همان_Secret_کلادفلر"
npm run webhook:set
```

سلامت Worker را از مسیر `/health` بررسی کن.

## اجرای محلی

`.env.example` را به `.dev.vars` کپی و مقدارهای محلی را وارد کن. فایل `.dev.vars` در Git نادیده گرفته می‌شود.

```bash
npm run dev
```

## GitHub Actions

در GitHub Secrets این موارد را اضافه کن:

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`

Workflow قبل از Deploy، بررسی نحوی و تست‌ها را اجرا می‌کند. Secretهای Worker را جداگانه در Wrangler یا Cloudflare Dashboard تنظیم کن؛ آن‌ها داخل GitHub Actions کپی نمی‌شوند.

## جریان کار کاربر

۱. **Search movie** یا **Search series** را بزند یا نام عنوان را مستقیم بفرستد.
۲. نتیجه را از دکمه‌های Inline انتخاب کند.
۳. اطلاعات عنوان را ببیند و از دکمه‌های News، IMDb page، Watchlist، Similar titles، فصل یا Site metadata استفاده کند.
۴. برای متادیتای سایت، URL صفحه جزئیات را ارسال کند.
۵. برای پرسش AI و پیشنهاد آثار مشابه، کلید API خودش را در **My API keys** ثبت کند.

## امنیت و محدودیت‌ها

- کلیدهای AI فقط در چت خصوصی دریافت می‌شوند و قبل از ذخیره رمزنگاری می‌شوند. بات تلاش می‌کند پیام حاوی کلید را حذف کند؛ اما چت بات تلگرام رمزنگاری سرتاسری ندارد و حذف پیام تضمینی نیست. در صورت احتمال افشا، کلید را باطل کن.
- کلید OMDb، Secret صاحب بات است و از کاربران دریافت نمی‌شود.
- بدنه Update تلگرام، کلید API و Secretها را در لاگ چاپ نکن.
- واکشی URL فقط HTTPS و دامنه‌های مشخص‌شده را می‌پذیرد، ریدایرکت به دامنه دیگر را رد می‌کند و فقط متادیتا را می‌خواند.
- KV سازگاری نهایی دارد؛ برای ترافیک بالا، D1 یا Durable Objects گزینه مناسب‌تری هستند.
- داده OMDb ممکن است ناقص یا قدیمی باشد؛ مقدار موجودنبودن را حدس نزن.
